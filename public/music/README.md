# Music

Add your own legally-owned copies of these four songs here, using these exact
filenames (the player's queue is already wired up to them):

```
perfect.mp3          Perfect, Ed Sheeran
photograph.mp3       Photograph, Ed Sheeran
lost-stars.mp3       Lost Stars, Adam Levine
shivers.mp3          Shivers, Ed Sheeran
gone-gone-gone.mp3   Gone, Gone, Gone, Phillip Phillips
```

A note on copyright: I can't provide the actual audio files (they're
commercially licensed music), so add copies you already own. If you'd rather
sidestep any licensing question entirely, four romantic instrumentals work
just as well, since the player only cares that a file exists at that path.

Missing a track? Leave that file out. The player detects the failure, shows
a small "unavailable" label next to the artist name instead of breaking, and
you can still skip past it with Next.

## Optional album art

Drop matching cover images in `public/images/` using these filenames, and
they'll appear in the player automatically:

```
album-perfect.jpg
album-photograph.jpg
album-lost-stars.jpg
album-shivers.jpg
album-gone-gone-gone.jpg
```

No art file? The player quietly falls back to a plain music icon, never a
broken image.
