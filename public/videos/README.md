# Videos

This folder is reserved for the video memory cards described in the spec
(Chapter Three's movie-card section). The current release ships with the
photo gallery wired up; video cards are one of the pieces planned for the
next pass (see the project README's "What's next" section).

When that's added, drop clips here as:

- `video1.mp4`, Kilimanjaro
- `video2.mp4`, Pleasure Park
- `video3.mp4`, Cinema
- `video4.mp4`, any other memory you want included

Keep clips short (under 30 seconds) and compressed (H.264, under ~10MB each)
so they stay fast on mobile data. Videos should never autoplay.
